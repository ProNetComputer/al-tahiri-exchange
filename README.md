## 🚀 كيفية الرفع على GitHub و GitHub Pages

1. **إنشاء مستودع جديد (Repository):**
   - سجّل دخولك إلى [GitHub](https://github.com).
   - اضغط على **New repository**.
   - اختر اسماً للمستودع (مثلاً: `al-tahiri-exchange`).
   - اجعله عاماً (`Public`).

2. **رفع الملفات:**
   - فك ضغط ملف الـ ZIP الذي قمت بتحميله.
   - في صفحة المستودع على GitHub، اضغط على **Add file** ثم **Upload files**.
   - اسحب ملف `index.html` وملف `README.md` إلى المستودع ثم اضغط **Commit changes**.

3. **تفعيل الموقع مجاناً عبر GitHub Pages:**
   - من داخل المستودع، اذهب إلى تبويب **Settings**.
   - من القائمة الجانبية اختر **Pages**.
   - تحت قسم **Build and deployment** > **Branch**:
     - اختر الفرع `main` (أو `master`).
     - اختر المجلد `/ (root)`.
     - اضغط **Save**.
   - خلال دقيقة واحدة سيصبح موقعك متاحاً على الإنترنت برابط مباشر مثل:
     `https://<username>.github.io/al-tahiri-exchange/`
